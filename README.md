# My Portfolio Site

As the name suggests, this is a portfolio site I built to practice HTML, CSS, and JavaScript.

## Description

It's open source &mdash; feel free to use it as a reference for your own website or for any other purpose, as long as it complies with the MIT license. See the section near the bottom for more details.

This portfolio website was initially created as part of an assignment from my teacher, meant to serve as a proof-of-concept for a hypothetical business.

### Features
* Semantic HTML layout for better accessibility and SEO.
* Responsive design with a navbar that adapts to different screen sizes.
* Easy navigation through the navigation bar at the top of the website.
* Simple and effective user experience, designed for clarity and ease of use.
* Full accessibility, including support for screen readers and keyboard navigation.
* A button that copies my email address to your clipboard.
* Footer with links to social profiles and other relevant sites.

## Getting started

To use or explore this site:
* Fork the repository.
* Clone your fork locally.
* Open the [index.html](index.html) file in your browser.
